# Ren'Py Visual Novel Game

A mini game developed using Python and Ren'Py, featuring interactive storytelling, dialogue systems, and branching gameplay elements.

## Features
* Interactive dialogue system
* Story-based gameplay
* Character interactions
* Multiple scenes and events
* Visual novel style interface

## Technologies Used
* Python
* Ren'Py

## Project Structure
* `.rpy` files for game scripts and dialogue
* Image and audio assets for gameplay experience

## How to Run
1. Open the project using Ren'Py
2. Launch the project from the Ren'Py Launcher
3. Start the game

## Purpose
This project was created to explore game development, storytelling, and interactive user experiences using Python and Ren'Py.
